# Python Programming Lab

This project contains the Python Programming Lab programs for Units 1 through 5.

- `unit_1/` contains basic input, calculations, and billing programs.
- `unit_2/` contains prime-number, factorial, Fibonacci, and OTP programs.
- `unit_3/` contains pandas, CSV, JSON, and student class programs.
- `unit_4/` contains student, payroll, and JSON log management programs.
- `unit_5/` contains bank account, library, dice, and retail sales programs.

## Running a program

Open this folder in VS Code, open any `.py` file, and select **Run Python File**. You can also run a file from the integrated terminal:

```bash
python3 unit_1/01_student_information.py
```

The programs use only Python's standard library.
